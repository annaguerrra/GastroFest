# Curitiba Gastronomic Festivals

A website created to centralize information about gastronomic festivals in Curitiba, making it easier to discover local food events and the restaurants participating in them.

## About the Project

Curitiba hosts several gastronomic festivals throughout the year, involving different restaurants, cuisines, menus, and locations.

The goal of this project is to gather this information in one place through a simple and organized website, allowing users to explore:

* Gastronomic festivals happening in Curitiba
* Participating restaurants
* Festival dates
* Locations
* Restaurant and event information
* Special menus or dishes offered during each festival

The project is being developed using only **HTML and CSS**, focusing on page structure, styling, responsiveness, and user experience.

## Main Objectives

The website aims to:

* Centralize information about Curitiba's gastronomic festivals
* Help users discover participating restaurants
* Present festival information in a clear and accessible way
* Practice semantic HTML and CSS
* Develop a responsive interface
* Practice collaborative development using Git and GitHub

## Development

This project is being developed collaboratively by three contributors.

To keep development organized, each contributor can work on a separate branch and submit changes through Pull Requests before merging them into the main branch.

Example:

```text
main
├── feature/home-page
├── feature/festivals-page
└── feature/restaurants-page
```
